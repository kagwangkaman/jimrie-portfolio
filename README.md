# Jimrie Parado, E-Portfolio

This is my e-portfolio for DCIT 26, Application Development and Emerging Technologies 2. I am Jimrie Parado, an Information Technology student at Cavite State University Tanza Campus. I build clean and responsive web applications.

## Sections

- Home, intro, photo, download CV, link to projects
- About, background, skills, interests
- Projects, 4 projects with short info, tags, details, GitHub links
- Resume, education, experience, skills, download CV
- Contact, email and social links, validated contact form

## What I used

- React with useState, conditional rendering, and event handling
- Vite for dev and build
- Tailwind CSS for layout and styling
- IntersectionObserver with useEffect for scroll spy nav
- Blob for client side CV download as text file

## Features

- View more and view less for about text and project list
- Show and hide details per project
- Download CV button in home and resume
- Contact form with name, email, and message validation
- Mobile menu that opens and closes
- Sidebar nav that highlights the active section
- Dark mode support with Tailwind classes

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173, then check nav links, mobile menu, view more buttons, project details, contact validation, and CV download.

## Build

```bash
npm run build
npm run preview
```

## Deploy on Vercel

1. Push to GitHub
2. Import the repo in Vercel
3. Use framework Vite, build command npm run build, output dir dist
4. Deploy, then open the live URL and check all 5 sections
